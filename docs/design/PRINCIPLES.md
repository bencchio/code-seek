# Principles

## Design Priorities

1. Precision
2. Speed
3. Memory Efficiency
4. Extensibility

## Information Philosophy

Code Seek exposes facts, not judgments.

Prefer information over interpretation.

## Non-Goals

Code Seek does not:

- Evaluate code quality
- Enforce architecture
- Rank implementations
- Decide what code is good or bad

## Change Philosophy

Every change should leave the codebase slightly better than it was found.

Prefer small coherent improvements over large unrelated refactors.

## Clarification Principle

When requirements are incomplete or ambiguous:

- Ask questions
- Do not invent missing requirements
