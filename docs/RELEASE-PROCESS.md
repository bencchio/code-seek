# Release Process

## Feature Versions (Z=2-89)

May add:

- New capabilities
- New commands
- New language support

## Refactor Versions (Z=1)

May:

- Reorganize code
- Improve consistency
- Reduce complexity

## Stabilization Versions (Z=90-99)

Focus on:

- Bug fixes
- Tests
- Documentation
- Cleanup

Avoid major new features.

## Release Versions (Z=0)

Must:

- Be documented
- Pass verification
- Be ready for use
